# StockHub 📦

StockHub is a modern, responsive web-based warehouse product management and inventory tracking system. It is designed to streamline stock control, provide real-time status alerts, and optimize warehouse workflows.

## 🚀 Key Features

* **Real-Time Inventory Dashboard:** Overview of total SKUs, low-stock items, total inventory value, and unit counts.
* **Product & SKU Management:** Add, edit, organize, and filter products by category and stock status.
* **Dynamic Barcode Generator:** Client-side Code128 barcode generation for every product SKU.
* **Warehouse Bin Map:** Visual storage zone layout colored dynamically by fill percentages.
* **Restock Predictor:** Automated forecasting of days left until stock depletion based on daily usage rates.
* **Activity Audit Log:** Track recent add, edit, and delete actions with timestamps.
* **Secure Authentication:** User signup and login session management.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Single-Page Application architecture)
* **Database Integration:** MySQL (Backend database structure configured for inventory records)
